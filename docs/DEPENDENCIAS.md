# Dependencias y atribuciones

El proyecto emplea [Lean 4](https://github.com/leanprover/lean4) y [Mathlib](https://github.com/leanprover-community/mathlib4). Mathlib se distribuye bajo Apache 2.0. No se redistribuyen sus árboles de fuentes, dependencias transitivas ni cachés en este repositorio. Lake los obtiene por separado; su licencia y sus avisos originales siguen siendo aplicables.
